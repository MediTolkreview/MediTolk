# Openbare assets

Voeg uitsluitend gecontroleerde bestanden met vastgelegde herkomst en gebruiksrechten toe.
Registreer noodzakelijke assets daarna expliciet in `pubspec.yaml`.
Noto-fonts, vlaggen en de 2D-pop zijn nog niet geïmporteerd.
Gebruik geen patiëntfoto's, medische dossiers of commerciële bronbestanden zonder besluit over publicatie.
